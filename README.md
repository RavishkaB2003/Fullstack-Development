# ⚡ Awwwards Bento Portfolio & Motion Dock

An interactive, high-performance portfolio featuring bento-grid layouts, dynamic filtering, and physics-driven motion dock.

## 🛠️ Tech Stack
- **Framework:** React 19 + Vite
- **Language:** TypeScript (`strict` mode)
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`)
- **Animation & Physics:** Framer Motion (Upcoming)

## 📁 Project Structure
```text
awwardsportfolio/
├── public/              # Static assets & icons
├── src/
│   ├── assets/          # Project visual assets
│   ├── components/      # Modular typed React components
│   ├── App.tsx          # Root application layout
│   ├── index.css        # Tailwind CSS entry point
│   └── main.tsx         # React root mounting
├── tsconfig.json        # TypeScript configuration
└── vite.config.ts       # Vite + Tailwind + React plugins
```

## 🚀 Getting Started
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run TypeScript compilation & production build
npm run build
```
